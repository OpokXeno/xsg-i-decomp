# Source

This tree contains recovered source and source organized by subsystem. The
original game units are also represented in roots such as `main`, `ov01` through
`ov12`, `ssd`, and `rssd`; the build configuration defines the exact units.

The subsystem directories provide homes for code grouped by responsibility:
[core](core/README.md), [render](render/README.md), [audio](audio/README.md),
[input](input/README.md), [filesystem](filesystem/README.md), and
[savedata](savedata/README.md). See the [project README](../README.md) for the
matching build workflow.
